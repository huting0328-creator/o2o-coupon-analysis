# O2O 优惠券用户行为分析

## 项目简介

本项目基于 O2O 优惠券消费数据，对用户的优惠券领取和核销行为进行分析。

项目使用 MySQL 完成数据查询与聚合，并使用 Python（Pandas、Matplotlib）进行数据处理和可视化，重点分析用户距离、优惠力度和用户活跃程度与优惠券核销表现之间的关系，并根据分析结果提出相应的业务建议。

本项目将“领取优惠券后 15 天内完成消费”定义为核销成功。数据中共包含约 105 万次优惠券领取记录，其中约 6.4 万次在 15 天内完成核销，整体 15 天核销率约为 6.11%。

## 项目目标

本项目主要围绕以下问题展开：

1. 优惠券整体的领取和核销情况如何？
2. 用户与商家的距离是否与优惠券核销率有关？
3. 优惠力度和使用门槛与优惠券核销表现有何关系？
4. 不同优惠券活跃程度的用户在核销行为上有何差异？
5. 如何根据分析结果进行用户分层，并为优惠券投放提供参考？

## 技术栈

## 核心分析结果

### 1. 整体核销情况

数据中共包含 1,053,282 次优惠券领取记录，其中 64,395 次在领取后 15 天内完成核销，整体 15 天核销率为 **6.11%**。整体来看，大部分领取的优惠券并没有在规定时间内转化为实际消费。

### 2. 距离与核销率

用户与商家的距离和优惠券核销表现存在明显关系。距离为 0 时，15 天核销率约为 **11.57%**；距离增加到 1 后下降至 **5.01%**，之后整体继续下降。

这一结果表明，距离较近的消费场景具有更高的优惠券核销表现。

### 3. 优惠力度与核销率

不同折扣区间的核销率存在明显差异，但并没有表现出“优惠力度越大，核销率越高”的简单关系。

其中，实际折扣在 0.90–0.95 区间的核销率约为 **11.80%**，而 0.85–0.90 区间仅约为 **2.98%**。因此，优惠券效果不能仅通过折扣力度解释，还需要结合消费门槛、距离和用户特征进行分析。

### 4. 用户活跃度与核销表现

按照优惠券领取次数对用户进行分组后：

- 低活跃用户：**3.77%**
- 中活跃用户：**6.55%**
- 高活跃用户：**10.35%**

高活跃用户表现出更高的优惠券核销率，说明用户的优惠券活跃程度与核销行为存在较明显的关联。

## 业务建议

基于以上分析结果，可以考虑以下几个方向：

- **优先关注高活跃用户**：高活跃用户的优惠券核销表现明显高于低活跃用户，可以将其作为重点运营人群，并进一步观察不同投放策略下的实际效果。

- **结合距离进行优惠券推荐**：距离较近的用户具有更高的核销率，可以优先推荐附近商家的优惠券，减少领取后未及时使用的情况。

- **优化优惠券设计**：优惠力度与核销率并不存在简单的线性关系，因此优惠券设计不应只追求更大的折扣，还需要综合考虑最低消费门槛、优惠金额和目标用户特征。

- **对低活跃用户采用差异化策略**：可以尝试降低使用门槛、推荐附近商家或采用其他激活方式，并通过后续数据观察策略效果。

## 数据说明

本项目使用 O2O 优惠券消费数据进行分析，主要字段包括：

- `User_id`：用户 ID
- `Merchant_id`：商户 ID
- `Coupon_id`：优惠券 ID
- `Discount_rate`：优惠信息，包括直接折扣和满减形式
- `Distance`：用户与商户之间的距离
- `Date_received`：优惠券领取日期
- `Date`：实际消费日期

分析过程中，将用户领取优惠券后 **15 天内完成消费**定义为核销成功。

由于原始数据文件较大，项目仓库不直接上传完整数据集。

## 运行方式

1. 获取 O2O 优惠券原始数据，并将数据文件放入 `data/` 目录。

2. 安装项目所需的 Python 库：

```bash
pip install pandas matplotlib sqlalchemy pymysql jupyter
```

3. 在本地 MySQL 中创建 `coupon_analysis` 数据库，并将原始数据导入 `offline_transactions` 表。

4. 打开 `o2o_coupon_analysis.ipynb`，运行数据库连接单元格，并根据提示输入本地 MySQL 密码。

5. 按顺序运行 Notebook，即可完成数据处理、SQL 查询、可视化和分析。
